# HPC_EC7207_SpMV

## Overview

This project is focused on **High-Performance Computing (HPC)** techniques for implementing and optimizing **Sparse Matrix-Vector Multiplication (SpMV)**. The goal is to explore, implement, and analyze efficient algorithms and data structures for SpMV on modern computing architectures.

## Features

- Implementation of various algorithms for SpMV.
- Analysis and benchmarking of performance on different hardware.
- Comparison of storage formats for sparse matrices (e.g., CSR, COO, etc.).
- Modular, extensible code structure for experimentation and research.

## Getting Started

### Prerequisites

- C/C++ compiler (e.g., GCC)
- Make
- (Optional) MPI, OpenMP, or CUDA for parallel implementations

### Building the Project

```sh
make
```
Or refer to the provided build instructions in the repository.

### Running

Refer to the main executable or scripts in the repository for example usage. Typically, you will need to provide a sparse matrix file and a vector input.
